# Analyse du site

## Éléments communs

| Partie | Contenu | Balises |
|---|---|---|
| En-tête | Logo, panier, menu et recherche | `header`, `a`, `img`, `button`, `form` |
| Menu | Liens vers les pages du site | `nav`, `ul`, `li`, `a` |
| Contenu | Partie principale de chaque page | `main` |
| Pied de page | Contact, informations et réseaux | `footer`, `nav`, `a` |

## Accueil (`index.html`)

| Ordre | Bloc | Contenu |
|---:|---|---|

| 3 | Présentation | 2 phrases pour présenter le site |
| 4 | Catégories | 4 catégories avec une image |
| 5 | Produits | 4 cartes avec le prix et le stock |

## Fiche produit (`produit.html`)

Le fil d’Ariane, le nom du produit, 3 photos, le prix, le stock, la quantité, 4 caractéristiques et 6 produits similaires.

## Éléments repris sur plusieurs pages

Le menu, le pied de page et les cartes produit gardent le même style d’une page à l’autre.
